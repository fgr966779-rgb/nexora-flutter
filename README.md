# Nexora Flutter

> Гейміфікований додаток для заощаджень з XP-системою, бейджами, челенджами та аналітикою.

## 📊 Статистика

| Метрика | Значення |
|---------|----------|
| Файлів .dart | 107 |
| Рядків коду | 161,889 |
| Розмір | ~6 МБ |

## 🏗 Архітектура

```
lib/
├── core/           # Основні компоненти
│   ├── constants/  # Константи, кольори, типографіка
│   ├── extensions/ # Розширення для Dart типів
│   ├── theme/      # PS5 та Monitor теми
│   ├── utils/      # Утиліти (XP, streaks, haptic)
│   └── widgets/    # Повторно використовувані віджети
├── data/           # Дані
│   ├── models/     # Моделі (Transaction, Goal, Challenge)
│   ├── repositories/ # Репозиторії
│   └── services/   # Сервіси (Analytics)
├── features/       # Фічі
│   ├── analytics/  # Аналітика та графіки
│   ├── dashboard/  # Головний дашборд
│   ├── deposit/    # Депозити та челенджі
│   ├── final/      # Фінальні екрани
│   ├── gamification/ # Гейміфікація (бейджі, рівні)
│   ├── onboarding/ # Онбординг
│   ├── settings/   # Налаштування
│   └── social/     # Соціальні функції
└── router/         # Навігація (GoRouter)
```

## 🎮 Можливості

- **Система XP** — нарахування досвіду за депозити, серії днів, виконання цілей
- **Рівні та бейджі** — 10+ рівнів, 20+ унікальних бейджів
- **Челенджі** — щоденні та тижневі виклики для мотивації
- **Streak система** — відстеження серій заощаджень
- **Прогнозування** — три режими прогнозу накопичень
- **Аналітика** — графіки, статистика, історія транзакцій
- **Теми** — PS5 (темна) та Monitor (світла)
- **Налаштування** — безпека, бекап, профіль, сповіщення

## 🛠 Технології

- **Flutter** — UI фреймворк
- **Riverpod** — управління станом
- **GoRouter** — навігація
- **flutter_animate** — анімації
- **Provider** — додаткове управління станом
